NES emulator

Runs .nes cartridge files in your browser. It loads Super Mario Bros.nes from this folder automatically; add ?rom=File%20Name.nes to the address to load another one, or choose a file yourself.

Arrow keys move, Z is B, X is A, Enter is Start and Shift is Select. Supported cartridges: NROM, MMC1, UxROM and CNROM (many early and mid-era games). Sound isn’t emulated yet.
